## Standards

依据 `SPEC.md` 的异步处理、固定官方端点、远端输入验证、凭据与个人内容不进入日志等标准。

| 发现 | 修复与证据 |
|---|---|
| WebSocket 自动重定向可能把朗读文字发送到非预期源 | 完成握手后检查官方域名、协议、端口与路径，检查通过前不启动文字发送；模拟恶意源测试断言零文字发送。HTTP 禁止重定向，aiohttp 对跨源认证头另有剥离保护。 |
| SSE 使用无界行解析可能先分配超大内存再检查 | 改为按字节限制单事件与总响应，无换行超长流测试通过。 |
| `usage: null` 等异常用量字段可中断已完成工具后的后续请求 | 容错处理空值、错误类型、负数和非有限数；计数恢复/重置及空用量测试通过。 |
| 原生 HA DEBUG 会记录提示、流片段和工具结果；初版过滤还影响其他提供商错误 | 过滤两个原生对话记录器的 DEBUG 内容；错误脱敏限定本集成请求上下文。全局 DEBUG 作用范围在 README 明确说明。 |
| 卸载时过滤器和平台被移除，但在途模型、语音或工具仍可能继续 | Runtime 跟踪请求和 HA 创建的工具任务；先停止接收并取消、等待，再卸载和清理。活跃 SSE 卸载、消费者关闭和并行工具取消测试通过。 |

本轴发现 5 项，均已修复并有相应回归证据。最高影响问题是卸载后仍可能执行后续工具调用。

## Spec

依据批准计划的完整 Schema、完整工具配对历史、可配置超时、取消/卸载与禁止动作重放要求。

| 发现 | 修复与证据 |
|---|---|
| OpenAPI 3.0 可空字段表达与 JSON Schema 验证语义不一致 | 工具与任务统一转换为 OpenAPI 3.1 / JSON Schema，并执行本地字段、类型、概率与分布验证。 |
| 多轮图片可能使请求超过本地预算，按轮数限制不足 | 增加40 MiB历史字节预算与48 MiB请求预算；只裁剪完整用户轮次，当前轮次过大明确失败。 |
| STT 配置的网络超时没有传到请求 | 向 ASR 调用显式传递子项超时，原生 STT 测试检查实际请求的超时参数。 |
| 卸载/重配置没有停止在途调用，文件清理可能与上传竞争 | 取消并等待 Runtime 请求和工具任务后再清理；并行取消保存已完成结果，中断结果标记未知，不自动重放。 |

本轴发现 4 项，均已修复并有相应回归证据。最高影响问题是卸载与在途动作、文件清理之间的竞争。

### Standards

发现1项阻断问题：历史字节预算在逐条解析旧轮次时执行，可能将可删除的超大旧轮次误判为当前轮次超限，阻断后续短对话。已改为优先构建系统提示与真正当前轮次，再按完整历史轮次逆序纳入预算；超限旧轮次与更早历史整体删除。新增旧轮次裁剪与当前轮次拒绝两项回归，独立复查确认修复范围无剩余阻断项。

另排除 CI 生成的根目录 `test-results.xml`，避免无关的运行器环境元数据进入源码 ZIP，并补充打包断言。

### Spec

发现1项阻断问题：HTTP 响应流尚未完全关闭时就提交执行性工具 delta，关闭挂起/失败/取消可能导致动作已执行但调用与结果未进入历史。现先完整消费并成功关闭供应商流，再向 HA 提交 `native/tool_calls`。新增关闭成功、失败、取消三项回归，独立临时复现也确认修复后关闭阶段不执行动作。

本轮 Standards 1项、Spec 1项，均已修复；两个复查代理确认修复范围无剩余阻断项。
